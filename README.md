This repository features our entry for the make.fun bounty promoting make.fun's make-your-own-bounty feature on X. Our quoted post highlights how exciting it is to sponsor and create bounties on make.fun, accompanied by a real robot photo. Entries are scored by their replies, reposts, and quotes.

## Run it

To run the copy program locally:

```bash
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
